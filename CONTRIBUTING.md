# Contributing to yaagents-fastapi

This is a component of the [YAAgents](https://github.com/ai-mpathyminds/yaagents) project.

Please read the [contribution guidelines](https://github.com/ai-mpathyminds/yaagents/blob/main/CONTRIBUTING.md)
in the meta-repo before opening a pull request.

By contributing you agree to the Developer Certificate of Origin (DCO).
Sign your commits with `git commit -s`.
